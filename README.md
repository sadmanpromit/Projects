# Projects

A collection of academic, research, and software development projects by Sadman Sakib Khan Promit, covering artificial intelligence, software engineering, computer systems, digital logic, and related topics.

## Artificial Intelligence and Machine Learning

- **[Self-Reprogrammable Machines](./Self-Reprogrammable%20Machines)** — Experiments toward autonomous code generation and agentic execution, including speech processing, local Llama 3.1 70B inference, and Python code execution.
- **[Hate Detection](./Hate%20Detection)** — Binary text classification using fine-tuned BERT-Base and merged Reddit and Wikipedia datasets. Recorded 98.12% accuracy on a separate evaluation dataset.
- **[Sentiment Detection](./Sentiment%20Detection)** — Fine-tuning BERT-Base for sentiment classification on IMDb movie reviews, with 92.59% validation accuracy.
- **[Violence Detection](./Violence%20Detection)** — Video classification using ResNet152 and LSTM models to distinguish violent and nonviolent video samples.
- **[Animal Classification](./Animal%20Classification)** — Image classification experiments comparing ResNet152 and squeeze-and-excitation ResNet152 architectures, with model training and evaluation results.
- **[Disease Classification](./Disease%20Classification)** — Classification experiments on structured thalassemia data using CNN, LSTM, BiLSTM, and combined architectures.
- **[Fare Regression](./Fare%20Regression)** — Rideshare fare prediction using regression models, including XGBoost and CatBoost. The recorded XGBoost mean absolute error was $1.08.

## Software Engineering and Computer Systems

- **[Server Multiple Client Messaging](./Server%20Multiple%20Client%20Messaging)** — Java client-server messaging application using sockets and multiple threads to support multiple clients.
- **[Shell](./Shell)** — C-based shell project exploring command handling, processes, and threads on Windows.
- **[University Portal](./University%20Portal)** — University portal web application project with implementations both with and without a web framework.
- **[Utility Billing System](./Utility%20Billing%20System)** — Flask-based utility billing application with user accounts, bill management, PDF bill generation, and complaints.
- **[Tourism Management System](./Tourism%20Management%20System)** — Tourism management system design project with supporting report and draft documentation.
- **[Ultra Voice Reader](./Ultra%20Voice%20Reader)** — Published Chrome extension providing text-to-speech for text and documents. [Chrome Web Store listing](https://chromewebstore.google.com/detail/ultra-voice-reader/ihfgbijhdabgmohceeblogbklebnhdmf).
- **[YouTube Playlist Importer](./YouTube%20Playlist%20Importer)** — Independent Chrome extension for importing YouTube playlist entries from Excel workbooks through a browser side panel.

## Games

- **[Snake](./Snake)** — Java Swing implementation of Snake with difficulty settings, scoring, keyboard controls, and sound effects.
- **[Tic Tac Toe](./Tic%20Tac%20Toe)** — Tic-tac-toe implementations in C and HTML, including computer opponents and a Windows console game.

- **[5-bit Pattern Lock](./5-bit%20Pattern%20Lock)** — Digital pattern-lock circuit design in Logisim.
- **[AC–DC Converter](./AC%E2%80%93DC%20Converter)** — AC-to-DC converter circuit simulation in Multisim.
- **[Temperature Converter](./Temperature%20Converter)** — Temperature converter circuit project in Multisim.
