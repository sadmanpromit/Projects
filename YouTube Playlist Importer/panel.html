ABOUT

YouTube Playlist Importer

Import direct YouTube video links from a local Excel workbook into a playlist you choose, using your signed-in browser session. This is an independent, locally installed utility.

Version 1.4.1 · Private-use edition

HOW IT WORKS
  1. Open Options, choose an .xlsx or .xlsm workbook containing direct YouTube watch URLs, and set your exact Target playlist name.
  2. Press Start queue on Home. It requests workbook permission when needed and processes videos one at a time in a muted background tab.
  3. The importer locates Save to… and the playlist name you configured, and checks membership without toggling off an already saved video.
  4. Only after YouTube confirms does it remove the confirmed Excel row, shift subsequent rows and hyperlinks up, then verify the workbook write.
  5. The queue waits for your configured delay before continuing. An interrupted transaction is journaled for recovery.
REQUIRED EXCEL FORMAT

Use an .xlsx or .xlsm workbook. The simplest sheet has a header in row 1 and one song per row starting at row 2. The URL must point directly to a YouTube video, either as a normal cell value or an Excel hyperlink on the song title.

A: SongB: YouTube video URL
Example song 1https://www.youtube.com/watch?v=dQw4w9WgXcQ
Example song 2https://youtu.be/9bZkp7q19f0

You can instead put a clickable YouTube hyperlink directly in column A (with the song title as the display text) and omit column B. The sheet name and workbook filename can be anything; the importer finds the sheet with the most valid video links. Direct youtube.com/watch?v=… and youtu.be/… URLs work. Playlist, search and Shorts page URLs are not supported.

After confirming membership on YouTube, the extension deletes the entire processed worksheet row and moves later rows up. Make a backup first and don't open/edit the workbook simultaneously in Excel.

RETRIES & NOTIFICATIONS

Up to 3 automatic retries for YouTube failures. If they all fail, the queue pauses, sounds an alert when audio is permitted, and sends a desktop notification. Click the notification to bring the extension back into view on the Home tab.

WINDOWS & BACKGROUND USE

Keep the Chrome window containing the importer side panel maximized and open while the queue is running. Do not maximize another browser or application window over it, or fully cover the importer window.

You may keep using the device with other windowed (non-maximized) applications and browser windows/tabs, provided they do not fully cover or interrupt the importer window. Keep the side panel open. You can also use other tabs when the importer remains available.

This layout is recommended for reliability, not a guarantee. Chrome may still throttle background tabs, and YouTube can delay or change its controls. If the queue pauses, return to Home or Activity and check the error before retrying.

FILE ACCESS & SAFETY

The saved workbook reconnects automatically when Chrome permits. When access expires, selecting the file again or pressing Start queue can request renewed permission; the current queue is preserved.

File paths cannot override Chrome's security prompts. The Excel workbook is updated only after verification. Keep a separate backup before importing, and do not open or edit the workbook in another program while the queue is running.

The extension works in your existing YouTube session without uploading workbook contents to a third-party server or using the YouTube Data API. It is independent of YouTube and Google, and is not endorsed by either.
